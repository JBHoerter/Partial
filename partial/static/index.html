Keep the context.
Not just the code.

Partial records AI coding sessions — prompts, responses, and tool activity from Devin, Codex, and Claude, plus ChatGPT exports — and links them to Git commits as portable checkpoints stored on a metadata ref. Your history stays on your machine, in SQLite, and on a checkpoint branch you control.

Git-native checkpoints

Commits are captured as checkpoints on a dedicated metadata ref — never on your code branch — with diffs, linked sessions, and review notes.

Devin, included

First-class hooks for Devin, plus Claude, Codex streaming capture, and ChatGPT export import — all through one local CLI.

Your data, your server

Self-hosted single workspace. SQLite on disk, token-gated web UI, no accounts, no telemetry, no runtime dependencies.

How it works

01

Enable

partial enable merges Partial's hook entries into your repository's agent configuration without touching anything else.

02

Capture

Agent sessions stream into a local SQLite store — prompts, responses, tool calls — with best-effort secret redaction.

03

Review

Each commit can carry a checkpoint linking the sessions that touched its files. Browse, search, and annotate in the web UI.
